One out-of-office auto-reply, in the houseplant's own voice, for The
Houseplant Out-of-Office on make.fun. The human has gone away for two
weeks and left the plant in charge of the inbox — and the plant only
knows one reply: water. The setup and the payoff are the same thing
(the plant's single need), so every word earns its place, and the twist
lands in one read: from the plant's point of view, every problem has
the same solution. Exactly what the brief asks for.

## Run it

```sh
python3 main.py
```

This writes the auto-reply to `/output/entry.txt` (UTF-8, 1–120 characters).
